# Dragons Expeditions

Збірка Minecraft із драконами, дослідженням світу та грою на спільному сервері. Додаток для Windows встановлює збірку й перевіряє оновлення.

## Встановлення та запуск

1. [Завантажте інсталятор Dragons Expeditions](https://github.com/kanchii-dev/dragons-expeditions/releases/latest/download/Install-Dragons.cmd) і запустіть його у Windows.
2. Натисніть **Встановити**.
3. Надалі запускайте ярлик **Dragons Expeditions** на робочому столі. Додаток перевіряє власні оновлення та оновлення збірки.
4. У відкритому TLauncher натисніть кнопку входу в гру. Прямий запуск Minecraft без TLauncher ще не реалізований.

Якщо TLauncher не знайдено, виберіть його файл або ярлик у діалозі.

## Сервер

У списку серверів автоматично з’являється **Dragons Expeditions** — `molecule-smith.tun.ply.gg`. Інші сервери зберігаються.

## Оновлення з попередньої версії

Версії із самооновленням отримають зміни під час запуску. Старий ярлик **Play Dragons** буде перейменовано на **Dragons Expeditions**. Якщо самооновлення ще немає, один раз запустіть новий інсталятор.

Нові профілі називаються **Dragons Expeditions**. Уже встановлений профіль може зберігати технічну назву **Dragons**, щоб не переносити світи та налаштування.
